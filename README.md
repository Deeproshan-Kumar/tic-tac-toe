# 🎮 Tic-Tac-Toe Game

A simple and interactive **Tic-Tac-Toe** game built using **HTML, CSS, and JavaScript**. Play against a friend in a classic two-player game with a clean, responsive interface and instant winner detection.

---

## ✨ Features

* 🎲 Two-player gameplay (Player X vs Player O)
* 🏆 Automatic winner detection
* 🤝 Draw game detection
* 🔄 Restart/New Game functionality
* 📱 Responsive design for desktop and mobile
* ⚡ Lightweight and fast with no external libraries

---

## 🎮 How to Play

1. Player **X** starts the game.
2. Players take turns placing their marks on the 3×3 grid.
3. The first player to align **three marks** horizontally, vertically, or diagonally wins.
4. If all cells are filled without a winner, the game ends in a **draw**.
5. Click **Restart** or **New Game** to play again.
